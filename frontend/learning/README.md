# План обучения CAV в Planacry

Страница `/learning/` внутри Planacry: план (Rust, базы данных, Linux, по ходу JS/HTML/CSS) по этапам, следующий шаг, прогресс по трекам, вопросы для самопроверки и журнал уроков.

Каждый пункт плана — задача в проекте «CAV · обучение» в Planacry. Галочка на странице = статус задачи на доске, и наоборот.

## Что в папке

- `index.html`, `learning.css`, `learning.js` — сама страница (без сборки и библиотек);
- `plan-data.json` — план, 138 пунктов;
- `planacry-sync.mjs` — то же, что кнопка синхронизации, только из терминала (Node 18+).

## Установка

**Вариант 1** — твой Planacry это git-репозиторий:

```
cd E:\work\Labs\planacry
git fetch https://github.com/cryzis333/plancry claude/learning-plan
git checkout FETCH_HEAD -- frontend/learning
```

Команды кладут только папку `frontend/learning`, остальные файлы не трогают. Потом её можно закоммитить у себя.

**Вариант 2** — без git: скачай папку `frontend/learning` с GitHub (репозиторий `cryzis333/plancry`, ветка `claude/learning-plan`) и положи в `planacry/frontend/learning/`.

## Запуск

```
cd backend
cargo run
```

Открой http://127.0.0.1:8080/learning/ и нажми «Создать проект «CAV · обучение» в Planacry». Появится проект со 138 задачами, 6 из них уже done (это сделанное на уроках).

Или то же самое из терминала, из папки planacry:

```
node frontend/learning/planacry-sync.mjs --dry-run   # только показать, что будет создано
node frontend/learning/planacry-sync.mjs
```

## Как страница связана с Planacry

- В описании каждой задачи стоит тег `#cav-learn:<id пункта>`, по нему страница находит свою задачу. Тег не удаляй. Всё остальное (название, описание, часы, статус) меняй в Planacry как хочешь.
- Галочка ставит задаче `done`, снятая галочка — `backlog`. Статус `doing` показывается бейджем «в работе». Часы, записанные в Planacry, видны у пункта и в сумме по этапу.
- Синхронизация только добавляет: недостающие задачи и отметки «засчитано на уроке». Она ничего не удаляет и не трогает твои часы, переименования и задачи без тега. Если она оборвалась, просто запусти её ещё раз: уже созданное не задвоится.

## Как приходят обновления

1. После урока Claude обновляет `plan-data.json` на GitHub: новые пункты, «засчитано на уроке», запись в журнале.
2. Страница при каждом открытии берёт свежий план с GitHub (в шапке будет «план: GitHub, свежий»). Без интернета берёт локальную копию.
3. Если в плане есть то, чего нет в Planacry, сверху появится «В плане обновления: …». Нажми «Синхронизировать» (или запусти `planacry-sync.mjs`).

Чтобы обновить и саму папку у себя, повтори команды из варианта 1.

## Без Planacry

Если открыть `index.html` без Planacry (просто файлом), страница работает автономно: галочки хранятся в браузере, внизу есть экспорт, импорт и сброс. План в этом случае берётся с GitHub, так что нужен интернет. В Planacry такие галочки сами не переедут.

`?plan=local` в конце адреса — взять план из папки, не обращаясь к GitHub.
